# LocoLib

LocoLib is a localization library for robotics applications. It provides a particle filter implementation to estimate the position and orientation of a robot using sensor data.

## Features

- Particle filter for localization
- Sensor model integration
- Initialization with normal and uniform distributions
- Angle function for orientation estimation

## Installation

### Depot Installation (Recommended)

To install the depot, first add the depot to your project:

```bash
pros c add-depot https://github.com/alexDickhans/loco-lib/raw/refs/heads/depot/stable.json
```

You're all set! Take a look at the [Annotated Example](https://loco.dickhans.net/en/latest/tutorials/example.html) next!
